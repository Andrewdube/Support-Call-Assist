1. Confirm the AC adapter LED / charging LED. Try a known-good Lenovo USB-C or slim-tip adapter of the correct wattage.
2. Perform a power drain: unplug AC, disable the built-in battery (BIOS > Config > Power > Disable built-in battery, or insert a paperclip into the emergency reset hole for models that have one), hold power 15-20 seconds, reconnect AC only and power on.
3. Remove docks, USB devices and external displays. Test with AC only.
4. Listen for fan / beep codes; note any LED blink pattern (Lenovo beep/LED code lookup).
5. If the system powers on with AC only but not battery: battery fault likely - run Lenovo Diagnostics battery test.
6. If no power with known-good adapter after drain: system board fault likely. Verify warranty/entitlement on the serial and dispatch a system board (onsite or depot per entitlement).
